# Jenkins Integration with GitHub

## Aim
To integrate Jenkins with a GitHub repository for automated source code retrieval and build verification

## Project Files
- `README.md` - Project documentation.
- `index.html` - Sample HTML webpage.
- `app.py` - Python program used to verify Jenkins execution.

## Tools Used
- Git
- GitHub
- Jenkins
- Python
- HTML

## Procedure
1. Create a GitHub repository named `devops-demo`.
2. Add the project files to the repository.
3. Configure a Jenkins Freestyle project.
4. Connect Jenkins to the GitHub repository.
5. Configure build commands.
6. Run the Jenkins build.
7. Verify the results using Console Output and Workspace.

## Expected Result
Jenkins successfully retrieves the source code from GitHub and executes the configured build commands.

## Conclusion
This practical demonstrates how Jenkins integrates with GitHub to retrieve source code and automate basic build verification.
